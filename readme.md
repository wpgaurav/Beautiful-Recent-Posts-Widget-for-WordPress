## Description

Beautiful Recent Posts Widget (BRPW) is a clean, minimal sidebar widget that displays your recent posts in a beautiful way with featured images, dates, and comment counts.

### Features

* **Lightweight & Fast** - Minimal CSS with conditional loading
* **Modern Code** - Updated to latest WordPress coding standards
* **Retina Ready** - High-resolution thumbnail support
* **Customizable** - Choose number of posts (1-10)
* **Optional Button** - Add "Read More" button linking to any page
* **Responsive** - Works perfectly on all devices
* **Post Format Support** - Handles quotes, asides, and standard posts
* **Performance Optimized** - CSS only loads when widget is displayed

### Requirements

* WordPress 5.0 or higher
* PHP 7.0 or higher

## Installation

1. Upload the plugin folder to `/wp-content/plugins/` or install through WordPress dashboard
2. Activate the plugin through the 'Plugins' menu in WordPress
3. (Optional) Regenerate thumbnails for existing posts
4. Go to **Appearance → Widgets**
5. Drag **Beautiful Recent Posts** widget to your desired sidebar
6. Configure the widget settings

## Widget Settings

* **Title** - Widget title displayed in your sidebar
* **Number of posts** - Choose how many posts to show (1-10)
* **Button Text** - Optional text for "Read More" button
* **Link Destination** - Choose which page the button links to
